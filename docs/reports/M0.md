### Deviations from SPEC.md (SPEC.md has been updated accordingly)

1. **V5.1** — `type: folder` on the whole `webext/src` would have nested everything under
   `Resources/src/`. `project.yml` lists each top-level entry of `webext/src` instead.
   Consequence: **a new top-level file or folder in `webext/src` must be added to
   `project.yml`.**
2. **`PRODUCT_NAME` has no space** (`MaRecherche`, `MaRechercheExtension`); the
   user-visible name comes from `CFBundleDisplayName`. Spaces in product names break the
   Swift module name used by `NSExtensionPrincipalClass`.
3. **Self-heal order** — the spec switched the DNR rules *after* `tabs.update`. With a
   public engine that is also an intercepted one (e.g. Google) and `onlyAddressBar` off,
   the still-active "private" rules would bounce the tab straight back. Rules are now
   switched first (`fallBackToPublic` in `background.js`).
4. **Serialized background work** — alarm, config change, popup and navigation handlers
   all go through one promise queue, so two `refresh()` never interleave.
5. **`setMode` validates before saving** — an invalid stored config makes `loadConfig`
   fall back to full defaults, which would have wiped the private URL.
6. Default probe path is `/healthz` (SearXNG's liveness endpoint) instead of `/`.
7. Added `lib/i18n.js`, `ui.css`, `test/probe.test.js`, `test/locales.test.js`,
   `scripts/preview_ui.py`, and an in-app `Logo` image set.
